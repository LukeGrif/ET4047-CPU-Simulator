# ET4047 — CPU Visual Simulator (University of Limerick theme)

A University of Limerick–themed build of the
[CPU Visual Simulator](https://cpuvisualsimulator.github.io/) by Jonathan Cancelli,
used in the **ET4047 Embedded Software** labs (Dept. of Electronic & Computer Engineering).

- **Original simulator:** https://cpuvisualsimulator.github.io/
- **Lab documents:** https://lukegrif.github.io/LAB-ET4047/

## What changed from the original

- `ul-theme.css` — UL colour palette and header styles, matching the Lab Documents site.
- `index.html` / `manual.html` — UL / E&CE header with links back to the lab documents and the original simulator.
- `build/app.bundle.js` — the window-fit calculation now leaves room for the header and centres the simulator.
- `assets/` — UL and E&CE logos.

The simulator itself is otherwise unchanged; all credit for it goes to the original authors
(see the in-app *Copyright* notice).
